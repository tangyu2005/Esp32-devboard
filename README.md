## 核心约束（来自任务书）

| 项 | 要求 |
|---|---|
| 板形 | 矩形，最长边 ≤10cm |
| 丝印 | 完善：位号、接口名、按键功能、极性、测试点、板名版本 |
| 按键 | 复用加热台项目的型号和封装 |
| 主控 | ESP32-WROOM-32E 模组 |
| 天线 | 严格留净空区 |
| 布局 | 分区合理：天线→模组→电源→接口→按键排针 |

---

## 开工三步

1. 读 `ESP32/01-任务与需求/开发板设计任务书.md`
2. 填 `ESP32/01-任务与需求/按键复用清单.md`（加热台按键型号）
3. 定 EDA 工具和板子尺寸，开始画原理图
