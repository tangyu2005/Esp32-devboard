# ESP32 开发板设计任务书

> 目标：从零独立设计一块 **可打样、可焊接、可跑通** 的 ESP32 开发板。这是求职作品集的核心项目。

---

## 一、一句话任务

画一块 **矩形、最长边不超过 10cm** 的 ESP32 开发板，**丝印完善**、**复用加热台项目的按键**、布局合理，完成原理图 → PCB → 打样 → 焊接 → 跑通全流程。

---

## 二、硬性约束（必须满足）

| 约束 | 要求 | 验收方法 |
|---|---|---|
| 板形 | 矩形，最长边 ≤ 10cm | 在 PCB 里量板框尺寸 |
| 丝印 | 完善、清晰、无歧义（详见第四节） | 打印 1:1 图纸目检 |
| 按键 | 复用加热台项目的按键封装和型号 | BOM 里按键型号与加热台一致 |
| 主控 | ESP32-WROOM-32E 模组 | 规格书核对 |
| 天线 | 严格留净空区 | Gerber 各层检查 |
| 布局 | 分区合理，接口顺手（详见第五节） | 对着布局原则逐条打勾 |

---

## 三、功能需求

### 必需功能

1. **USB Type-C 供电与下载**：插上电脑就能供电、识别串口、一键烧录（DTR/RTS 自动下载）。
2. **最小系统**：模组 + 电源 + 复位 + 启动配置齐全，上电稳定。
3. **按键**：复用加热台的按键，至少 RESET、BOOT 两个（如加热台用的是轻触开关，直接沿用其封装）。
4. **指示**：电源 LED + 一颗可程控 LED。
5. **GPIO 扩展**：排针引出主要 GPIO，标注名称。
6. **丝印**：所有接口、按键、测试点、极性、版本信息齐全。

### 可选功能（有余力再加）

- 复位/BOOT 按键旁加测试点
- 板名、版本号、日期丝印
- 一个预留的 I2C 接口（4P 排针）

---

## 四、丝印完善标准（重点）

丝印是这块板的"门面"，也是面试官一眼能看到的专业度。要求：

### 必须有的丝印

- [ ] 每个元件的**位号**（R1、C1、U1...），方向统一，不被元件本体盖住
- [ ] 每个连接器的**引脚名称**：`5V`、`3V3`、`GND`、`TX`、`RX`、`EN`、`IO0` 等
- [ ]  connector 的**引脚 1 标记**（三角形或圆点）
- [ ] 按键功能标注：`RESET`、`BOOT`
- [ ] 极性元件标注：LED 的 `+`/`-`、`D1` 阴极标记、二极管方向
- [ ] 测试点标注：`3V3`、`GND`、`EN`、`BOOT`、`TX`、`RX`
- [ ] 板名 + 版本号 + 日期：如 `ESP32-DEV V1.0 2026-11`
- [ ] 天线区域标注：`ANTENNA KEEP-OUT - NO COPPER`（提醒自己也提醒别人）

### 丝印排版原则

- 字号不小于 0.8mm 高，线宽 0.15mm 以上（板厂能清晰印出）
- 丝印不要压在焊盘上，会被元件盖住或影响焊接
- 同类标注方向一致（全部水平或全部竖排），不要东倒西歪
- 板子空间和丝印冲突时，**功能标注优先于位号**

## 五、布局要求（重点）

### 分区（先分区再走线）

```
┌─────────────────────────────────────┐
│  [天线区]        [USB-C]            │
│  (净空、无铜)     (板边、易插拔)     │
│                                     │
│  [ESP32模组]     [LDO+电源]         │
│                                     │
│  [按键]          [LED]              │
│  RESET BOOT                         │
│                                     │
│  [排针 GPIO 扩展 - 板边两排]         │
└─────────────────────────────────────┘
```

### 布局原则

1. **天线优先**：先在板子一角画出天线净空区，所有层禁止覆铜/走线/放件。模组天线朝板边伸出，周围按规格书留空。
2. **电源靠近入口**：USB-C 在一侧，LDO 紧跟其后，输入输出电容紧贴 LDO 引脚。
3. **去耦贴近电源脚**：每个 VDD 脚旁边 100nF，距离越近越好。
4. **接口贴板边**：USB-C、排针靠板边，方便插拔和接线。
5. **按键顺手**：RESET、BOOT 放在好按的位置，不要被排针或模组挡住。
6. **功率走线短粗**：3.3V 走线 ≥0.5mm，GND 大面积铺铜。
7. **丝印留空间**：布局时就想到丝印，别把元件挤到没有地方写标注。

### 尺寸控制

- 矩形外形，建议 **80mm × 40mm** 或 **70mm × 50mm**（都 ≤10cm），好画好焊。
- 四角可加 3mm 圆角或倒角，避免锐角（可选）。
