# 原理图设计要点

> 按照 `01-任务与需求/开发板设计任务书.md` 画。这份只列关键检查点。

---

## 一、设计顺序

1. 新建工程，确认所有元件封装可用（尤其复用的加热台按键封装）
2. 画电源：USB-C → 保护 → LDO 3.3V
3. 画 ESP32 模组最小系统
4. 画按键（RESET / BOOT，照抄按键复用清单的电路）
5. 画 LED、排针、测试点
6. ERC 检查 + 逐脚核对

---

## 二、关键检查点

### 电源
- [ ] USB-C 的 CC1、CC2 各接 5.1kΩ 到 GND（漏了不供电）
- [ ] LDO 输出电流 ≥500mA（ESP32 Wi-Fi 发射峰值）
- [ ] LDO 输入/输出电容齐全（10µF + 100nF）
- [ ] 保险丝 / PTC 在 VBUS 路径上

### ESP32 模组
- [ ] EN 引脚 10kΩ 上拉，电容到 GND
- [ ] GPIO0 10kΩ 上拉，按键到 GND
- [ ] strapping 脚没有被外设拉错电平
- [ ] 未用 GPIO 没有硬接电源或地

### 下载电路
- [ ] CH340C（或 CP2102）供电正常、内置晶振款省外部晶振
- [ ] DTR/RTS 接 EN 和 GPIO0，**照官方参考电路**，不要自己发明
- [ ] USB D+/D- 串 22Ω，靠近接口加 ESD 保护

### 按键（复用加热台）
- [ ] 型号与加热台一致（见 `按键复用清单.md`）
- [ ] 4 脚按键确认了内部连通关系
- [ ] 丝印标注 RESET / BOOT

---

## 三、逐脚核对表

打开 ESP32-WROOM-32E 规格书，逐脚打勾：

- [ ] 每个电源脚接 3.3V，旁边有 100nF
- [ ] 每个 GND 脚接地
- [ ] EN / GPIO0 上拉到位
- [ ] UART0 TX/RX 交叉正确（TX→RX）
- [ ] 天线引脚按规格书处理（模组天线则留净空）
- [ ] 未用 GPIO 妥善处理
