# PCB 布局与丝印检查表

> 这份是任务书里"注意布局"和"丝印完善"两条要求的具体展开。画 PCB 时对着逐条打勾。

---

## 一、布局检查（画之前先分区）

- [ ] 天线净空区已经画出，**所有层**禁止覆铜、走线、过孔、放件、丝印
- [ ] 模组天线朝板边伸出，周围按规格书留空
- [ ] USB-C 贴在板边，方便插拔
- [ ] LDO 紧跟 USB 入口，输入输出电容紧贴 LDO 引脚
- [ ] 每个 VDD 脚旁 100nF 去耦，距离 <2mm
- [ ] 按键（RESET/BOOT）位置顺手，不被挡住
- [ ] 排针贴在板边两排，方便接线
- [ ] LED 位置可见，不被模组或散热片挡住
- [ ] 板形是矩形，最长边 ≤10cm（实测尺寸：____ × ____ mm）

---

## 二、布线检查

- [ ] 3V3 走线 ≥0.5mm（按 500mA 峰值）
- [ ] GND 大面积铺铜，顶层和底层都铺
- [ ] 地过孔把两面的地缝合起来
- [ ] 信号线避免 90° 直角
- [ ] USB D+/D- 走线短、平行、下方有完整地平面
- [ ] DRC 零错误
- [ ] 没有鼠线残留

---

## 三、丝印检查（任务书重点要求）

### 位号
- [ ] 所有元件有位号（R1、C1、U1...）
- [ ] 位号方向统一，不被元件盖住

### 接口与功能
- [ ] 每个连接器引脚标注名称：`5V` `3V3` `GND` `TX` `RX` `EN` `IO0`
- [ ] 连接器引脚 1 有标记（三角或圆点）
- [ ] 按键标注 `RESET`、`BOOT`
- [ ] 测试点标注 `3V3` `GND` `EN` `BOOT` `TX` `RX`

### 极性
- [ ] LED 标注 `+`/`-` 或阴极标记
- [ ] 二极管方向标记
- [ ] 电解电容（如有）标注极性

### 板级信息
- [ ] 板名 + 版本 + 日期：`ESP32-DEV V1.0 2026-11`
- [ ] 天线区标注 `ANTENNA KEEP-OUT - NO COPPER`

### 丝印工艺
- [ ] 字号 ≥0.8mm 高，线宽 ≥0.15mm（板厂能印清）
- [ ] 丝印不压焊盘
- [ ] 同类标注方向一致
- [ ] 打印 1:1 图纸目检，确认可读

---

## 四、打样前最终检查

- [ ] Gerber 用查看器打开，逐层确认
- [ ] 天线净空区在**每一层**都是空的
- [ ] 板框闭合，尺寸 ≤10cm
- [ ] 钻孔文件与焊盘对应
- [ ] 丝印 1:1 打印出来看过
- [ ] BOM 里按键型号与加热台一致

---

## 五、布局草图（可手绘拍照放这里）

> 画 PCB 前先手绘一张分区草图：天线在哪、USB 在哪、模组在哪、按键在哪、排针在哪。草图确认后再进 EDA 软件。
